# NEXORA Architecture

NEXORA separates control, intelligence, execution, governance, quality, memory, media, and integrations.

## Request lifecycle

Request -> Research -> Task Intelligence -> Decompose -> Select Specialists -> Specialist Brief -> Prompt Engineering -> Execute -> Evaluate -> Repair/Retry -> Approval -> External Execution -> Analytics -> Memory.

## Principles

- Agents are scoped workers.
- Capabilities are provider-neutral contracts.
- Consequential external actions pass through policy and approval.
- External content is untrusted input.
- Major outputs are evaluated before acceptance.
